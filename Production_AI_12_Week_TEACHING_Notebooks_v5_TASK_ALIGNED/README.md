# Production AI Teaching Notebooks v5 — Excel Task Aligned

这版重点解决“Excel 写了作业，但 Notebook 不知道去哪做”的问题。

每周 Notebook 开头新增：
- Excel 5 个任务 1:1 对照
- Task 3/4/5 的参考答案 / 参考实现 / 验收标准
- Task 1/2 的知识点与 Checkpoint 验收

使用顺序：
1. Excel 看本周 5 个任务；
2. 看课程；
3. Notebook 学知识点；
4. 完成 Task 3/4/5；
5. 再打开参考答案；
6. 回 Excel 打勾。
